**A correction to the record.** Session 14's commit `6acd199` claimed the KODEX capture
"carries a NAV token, an embedded timestamp and large integers" as evidence it was not an
empty shell. That was wrong, and I found it by parsing the stored bytes rather than
trusting the earlier claim:

- `253039467` → a **Google Analytics ID** (`UA-253039467-1`), not a fund figure
- `20260728070300` → a build timestamp
- `하이닉스` → inside a marketing blurb ("AI반도체 TOP2…")
- `NAV` → a JavaScript label string
- The data-bearing check (`순자산총액` / `기준가격`, the actual Korean AUM/NAV labels) → **False**

The lesson is the same one the figure audit surfaced: a claim drifts toward what the
author wanted to see unless something checks it against the actual bytes. "Verified not an
empty shell" was true (136KB) and irrelevant (136KB of marketing JS).

**Read it as the reflected-process thesis in a convergence estimate.** The
barrier-constrained premium is *highly* persistent — ρ ≈ 0.94 one day out, still 0.88
twenty days out, t-stat 129. The fungible control has **no** persistence: ρ ≈ 0.04,
statistically insignificant, R² ≈ 0.002. A premium held behind a one-sided barrier
mean-reverts on a scale of *months*; a freely convertible pair's premium is same-week
noise around parity. The identical estimator produces both.

**⚠️ The 227-day half-life is flagged in the module as an extrapolation.** ρ never crosses
0.5 within the 20-day fitting window, so the figure comes from the exponential fit beyond
range. It says "slow" reliably; the exact number does not. A convergence trade against
this regime is betting against a months-long half-life, and that qualitative fact is the
robust one.

**SKHY: scored, not fitted, and honestly out of support.** At n=12 it is below the 20-obs
minimum to estimate even its own single-horizon persistence — the module returns the
out-of-support answer rather than a number. Adjacency to `one_way_constrained` is by name
only; it was not used to fit that regime, and no call is resolved.
